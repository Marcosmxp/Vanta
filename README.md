# Vanta

Vanta is a native mobile betting platform under active development.

## Current milestone

**MVP v0.0.0.1** — React Native mobile client, Go server-authoritative backend, PostgreSQL ledger foundation, and Plinko as the first game.

## Engineering principles

- Server-authoritative financial and game logic
- Security by design
- Immutable and auditable financial ledger
- Clear feature-based module boundaries
- No secrets or privileged credentials in client code or Git history
- Explicit separation of development, staging, and production environments

> Real-money operation, payments, KYC, licensing, and jurisdiction-specific compliance are intentionally excluded from the development bootstrap and must be completed before any production-money use.
